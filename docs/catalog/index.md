# Catalog

Everything nano-app gives ready to use. Each piece links to its reference.

| Catalog                      | Package                 | What you find                                    |
| ---------------------------- | ----------------------- | ------------------------------------------------ |
| [Plugins](./plugins)         | `@nano-app/plugins`     | Groups of backend routes you mount with one line |
| [Controllers](./controllers) | `@nano-app/controllers` | The logic of common pieces of UI                 |
| [Mantine](./mantine)         | `@nano-app/mantine`     | Layouts, views and ready pages                   |

A controller has no markup, and a Mantine view has no logic of its own: each Mantine view takes a controller as it is. Use the Mantine view, or write your own view for the same controller.
