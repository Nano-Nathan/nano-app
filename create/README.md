# @nano-app/create

[![create](https://img.shields.io/npm/v/@nano-app/create?label=create)](https://www.npmjs.com/package/@nano-app/create)

Creates an app on nano-app: a backend and a frontend in one pnpm workspace, on the published packages.

```bash
pnpm create @nano-app my-app
cd my-app
pnpm install
cp .env.example .env
pnpm dev               # backend on :3000, frontend on :3001
```

**Documentation:** [reference](https://nano-app-docs.pages.dev/reference/create), and the [tutorial](https://nano-app-docs.pages.dev/tutorial/) to start.
